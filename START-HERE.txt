PrepList — unpack and run

1. You should see package.json in this folder.
2. In Terminal:

   npm install
   npm run dev

3. Open http://localhost:5174

To put it on GitHub (https://github.com/valeriely/preplist):

   git init
   git add .
   git commit -m "Add PrepList"
   git remote add origin git@github.com:valeriely/preplist.git
   git branch -M main
   git push -u origin main
